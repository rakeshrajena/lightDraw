# LightDraw.js v1.2.0 Release Notes

**Release date:** 2026-07-22  
**npm:** `lightdraw@1.2.0`  
**GitHub:** [rakeshrajena/lightDraw](https://github.com/rakeshrajena/lightDraw)  
**Playground:** [https://rakeshrajena.github.io/lightDraw/](https://rakeshrajena.github.io/lightDraw/)

---

## Summary

v1.2.0 is a **backward-compatible minor** release. It deepens every domain module: richer dashboards, automotive telltales, production-grade diagram wire flow (status tint, smart routing, CAN bus hops), and higher-fidelity JSON export.

## Highlights

| Area | What's new |
|------|------------|
| **Dashboard** | Multi-series auto palette colors; grouped side-by-side bars; **`dataTable`** with search + stripes |
| **Automotive** | P0 telltales (`checkEngineLamp`, beams, parking, `pedestrianDetection`); **Individual dash** demo |
| **Diagram flow** | Marching dashes + packets; **status tint** (idle→active→done); play / pause / resume mid-step |
| **CAN bus** | `Diagram.canNetwork` + virtual **bus-rail hops** so frames travel ECU → rail → ECU |
| **Routing** | True Manhattan 90° `orthogonal`/`smart`; free-port fan-out; live re-route on drag/resize |
| **Editor** | Node **rotate** handle; smarter bends + arrowheads + edge labels |
| **JSON export** | Opaque module `{ type, props }` leaves; optional `exportJSON({ compact: true })` |
| **Catalogs** | Expanded pipeline / schematic / network symbol libraries |

## Quick examples

### Wire flow with status tint

```javascript
const chart = LightDraw.Diagram.flowchart(app, data, {
  width: 800,
  height: 480,
  flow: {
    enabled: true,
    mode: 'both',
    playback: 'loop',
    statusHighlight: true,
    paths: [
      ['start', 'check', 'process', 'end'],
      ['start', 'check', 'end'],
    ],
  },
});
app.add(chart);
```

### CAN bus message path

```javascript
LightDraw.Diagram.canNetwork(app, {
  busLabel: 'CAN HS · 500 kbps',
  ecus: [
    { id: 'ecm', label: 'ECM', address: '0x7E0' },
    { id: 'tcu', label: 'TCU', address: '0x7E1' },
    { id: 'abs', label: 'ABS', address: '0x7E2' },
  ],
}, {
  width: 800,
  height: 400,
  flow: {
    enabled: true,
    mode: 'both',
    paths: [['ecm', 'tcu', 'abs']],
  },
});
```

### Multi-series chart + dataTable

```javascript
app.loadJSON({
  type: 'group',
  children: [
    {
      type: 'lineChart',
      props: {
        width: 420,
        height: 180,
        x: 24,
        y: 24,
        series: [
          { name: 'CPU', data: [22, 28, 31, 27, 35] },
          { name: 'Mem', data: [40, 42, 45, 44, 48] },
        ],
      },
    },
    {
      type: 'dataTable',
      props: {
        x: 24,
        y: 220,
        width: 420,
        height: 160,
        showSearch: true,
        columns: [
          { key: 'host', label: 'Host' },
          { key: 'status', label: 'Status' },
        ],
        rows: [
          { host: 'edge-1', status: 'ok' },
          { host: 'edge-2', status: 'warn' },
        ],
      },
    },
  ],
});
```

### Compact opaque JSON export

```javascript
const scene = app.exportJSON({ compact: true });
// or: app.export({ format: 'json', compact: true })
// Module widgets stay { type, props } — not expanded visual trees
```

## Migration from v1.1.0

- **No breaking API changes**
- New optional flow / status / CAN / export options — existing callers keep working
- Size gates raised for diagram (≤ 73 KB) and full (≤ 169 KB) gzip
- Prefer `lightdraw@1.2.0` or `lightdraw@1` on CDN after publish
