# LightDraw.js v1.1.0 Release Notes

**Release date:** 2026-07-19  
**npm:** `lightdraw@1.1.0`  
**GitHub:** [rakeshrajena/lightDraw](https://github.com/rakeshrajena/lightDraw)  
**Playground:** [https://rakeshrajena.github.io/lightDraw/](https://rakeshrajena.github.io/lightDraw/)

---

## Summary

v1.1.0 is a **backward-compatible minor** release focused on an interactive **Diagram studio**, a richer **live playground** on GitHub Pages, and production polish for demos and docs.

## Highlights

| Area | What's new |
|------|------------|
| **Diagram editor** | Drag nodes, **8-handle resize**, **wire bend points** (double-click) |
| **Network** | Large Visio/Cisco-style icon catalog (`listNetworkIcons`, `resolveNetworkIcon`) |
| **Org chart** | Minimize/expand with **descendant counts** (`−N` / `+N`); **unique branch colors** for N teams |
| **JSON** | `Diagram.toJSON` / `fromJSON`; demo dock shows full `{ type, props }` |
| **Playground** | Day/Night hub, Theme lab, live Scene / API docks, Help center |
| **Pages** | Demos deploy automatically to GitHub Pages on `main` |

## Quick examples

### Interactive network diagram

```javascript
const net = LightDraw.Diagram.network(app, {
  nodes: [
    { id: 'fw', label: 'NGFW', type: 'ngfw', x: 200, y: 40 },
    { id: 'db', label: 'SQL', type: 'sql_database', x: 200, y: 160 },
  ],
  edges: [{ from: 'fw', to: 'db' }],
});
app.add(net);
LightDraw.Diagram.fitToBounds(net, 800, 480, 24);
LightDraw.Diagram.installEditor(app, net, { mode: 'arrange', allowResize: true });
// Double-click a wire to add bend points
```

### Org chart with collapse

```javascript
const org = LightDraw.Diagram.orgChart(app, {
  name: 'CEO',
  children: [
    { name: 'CTO', children: [{ name: 'Eng Lead' }] },
    { name: 'CFO' },
  ],
}, { width: 900, height: 520 });
app.add(org);
LightDraw.Diagram.fitToBounds(org, 900, 520, 24);
LightDraw.Diagram.installEditor(app, org, { mode: 'arrange' });
// Click −N / +N on a card to minimize that branch
```

### JSON round-trip

```javascript
const json = LightDraw.Diagram.toJSON(org);
// { type: 'orgChart', props: { root, width, height, … } }
const rebuilt = LightDraw.Diagram.fromJSON(json.type, json.props, app);
```

## Migration from v1.0.0

- **No breaking API changes**
- New optional editor APIs — existing `Diagram.flowchart` / `network` / `orgChart` callers keep working
- Bundle size gates raised slightly for the diagram module (network icons + editor)
- Prefer `lightdraw@1.1.0` or `lightdraw@1` on CDN after publish
