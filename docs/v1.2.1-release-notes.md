## Summary

v1.2.1 is a **backward-compatible patch** on top of v1.2.0. It adds a **built-in diagram toolbar** (play / pause / replay + zoom / fit) whenever wire flow is enabled, and refreshes GitHub/npm README examples (JSON scenes for every diagram type + wire-flow GIF).

## Highlights

| Area | What's new |
|------|------------|
| **Flow toolbar** | Auto HTML overlay on the App host: ▶/⏸, ↻, zoom −/%/+, Fit |
| **Opt-out** | `flow.chrome: false` or `chrome: { flow, zoom }` |
| **API** | `Diagram.installToolbar` / `uninstallToolbar`; `App.getContainer()` |
| **Demo** | Diagram gallery uses the library toolbar (no duplicate HTML chrome) |
| **Docs / README** | JSON `scene` examples for flowchart, state, pipeline, network, CAN, schematic, UML, mind map, org; animated flow GIF |

## Quick example

```javascript
const flowchartScene = {
  type: 'flowchart',
  props: {
    width: 800,
    height: 480,
    data: {
      nodes: [
        { id: 'start', label: 'Start', type: 'start', x: 360, y: 24 },
        { id: 'end', label: 'Done', type: 'end', x: 360, y: 160 },
      ],
      edges: [{ from: 'start', to: 'end' }],
    },
    flow: {
      enabled: true,
      mode: 'both',
      paths: [['start', 'end']],
      // chrome: true by default → ▶⏸↻ + zoom
    },
  },
};

const chart = LightDraw.Diagram.fromJSON(flowchartScene.type, flowchartScene.props, app);
app.add(chart);
LightDraw.Diagram.fitToBounds(chart, 800, 480, 24);
LightDraw.Diagram.installEditor(app, chart, { mode: 'arrange' });
```

## Migration from v1.2.0

- **No breaking API changes**
- New default: when `flow.enabled` is on, a toolbar appears on the App host — set `flow.chrome: false` if you bring your own controls
- Ensure the App host has `position: relative` (library sets it when needed)
