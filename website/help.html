Quick start

Create an app, add a shape, animate it.

const app = LightDraw.createApp('#app', {
  renderer: 'canvas',
  background: '#0d1322',
});

const dot = app.circle({ x: 80, y: 80, radius: 18, fill: '#3ecfcf' });
app.add(dot);
dot.animate({ x: 260, duration: 900, loop: true, reverse: true });

Theme packs

One applyTheme / uiTheme call styles UI, charts, and diagrams. Edit Theme JSON live in the theme lab. 

app.applyTheme({
  preset: 'dark',
  primary: '#0ea5e9',
  text: '#f1f5f9',
  fontSize: '14px',
});

// Or load with the scene:
app.loadJSON({
  type: 'group',
  theme: { preset: 'slate', primary: 'pink' },
  children: [ /* … */ ],
});

Scene JSON

Describe widgets as JSON — great for AI, configs, and the live editors under every demo.

app.loadJSON({
  type: 'group',
  children: [
    { type: 'button', props: { label: 'Save', variant: 'primary', x: 16, y: 16 } },
    { type: 'gauge', props: { value: 72, size: 100, x: 16, y: 64 } },
  ],
});
